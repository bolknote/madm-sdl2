# Oxford 8-bit SSEM simulator (Alex Rogers)

Not Manchester Baby (32-bit store). Teaching simulator with **32 × 8-bit** words, 8-bit accumulator, 5-bit PC; encoding matches original opcodes.

| File | Source |
|------|--------|
| `manchester.html` | Blog embed page |
| `manchesterSSEM8bit.html` | Full-page simulator |
| `manchesterSSEM8bit.js` | Elm 0.18 compiled bundle (~230 KB) |

Programs are entered in the browser; no preset 32-bit `.store` images were extracted. Use for 8-bit encoding reference only.
